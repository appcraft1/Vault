# App Craft — Design Archive & Visual Moodboard

> **Curated Studio Design Archive** — Responsive, ultra-fast visual moodboard and UI/UX design library with integrated AI clarity enhancement, categorized search, dark/light theme, and multi-device persistence.

## 🚀 Features

- **Multi-Category Design Hub**:
  - UI/UX Mobile Apps (iOS & Android)
  - UI/UX Web Dashboards & SaaS
  - Wireframes, Component Kits & User Flows
  - Typography & Editorial Posters
  - Anime & Character Game Art
  - Wallpapers & Photography
- **Interactive Lightbox Experience**:
  - Double-click 250% Zoom & Pan navigation
  - Smart Aspect-Ratio detection (Long scroll vs Fit view)
  - Native Fullscreen Mode (Press `F`)
  - Direct bitmap copy to clipboard (Paste directly into Figma / Photoshop)
  - In-browser AI 4K Super-Resolution & Clarity Engine
- **Multi-Device Support**:
  - 100% responsive for Mobile (HP), Tablet, and Desktop
  - Touch gestures (swipe left/right to navigate images)
  - Local persistence via IndexedDB for custom uploads
  - Light & Dark theme toggle
