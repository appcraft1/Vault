# App Craft — Design Archive & Visual Moodboard

> **Curated Studio Design Archive** — Responsive, ultra-fast visual moodboard and UI/UX design library with integrated AI clarity enhancement, AI auto-detect upload system, categorized search, dark/light theme, and multi-device persistence.

## 🚀 Fitur Utama

- **Hub Desain Multi-Kategori**:
  - UI/UX Mobile Apps (iOS & Android)
  - UI/UX Web Dashboards & SaaS
  - Wireframes, Component Kits & User Flows
  - Typography & Editorial Posters
  - Anime & Character Game Art
  - Wallpapers & Photography
- **✨ AI Smart Auto-Detect Upload Modal**:
  - Deteksi otomatis Nama/Judul Desain (membersihkan format nama file & Title Case).
  - Klasifikasi otomatis Kategori berdasarkan aspek rasio dan kata kunci nama file.
  - Penentuan otomatis Folder Proyek fisik (`C:\Users\Asep\OneDrive\Gambar\App Craft\[Kategori]\`) dengan tombol 1-klik salin path.
  - Pembuatan otomatis Deskripsi bahasa Indonesia yang kontekstual memuat resolusi piksel dan peruntukan desain.
  - Tampilan Dark Glassmorphism modern tanpa scrollbar putih Windows yang kaku.
- **Interactive Lightbox Experience**:
  - Double-click 250% Zoom & Pan navigation
  - Smart Aspect-Ratio detection (Mode Fit Lebar scroll vertikal vs Fit Layar utuh)
  - Native Fullscreen Mode (Tekan `F`)
  - Direct bitmap copy to clipboard (Paste langsung ke Figma / Photoshop)
  - In-browser AI 4K Super-Resolution & Clarity Engine (Upscayl WebGL CAS Shader)
- **Multi-Device Support**:
  - 100% responsif di Smartphone (HP), Tablet, dan Laptop/Desktop
  - Gesture swipe layar sentuh untuk navigasi foto
  - Penyimpanan lokal IndexedDB untuk aset kustom antar-sesi
  - Mode Gelap & Terang

## 📁 Struktur Folder Proyek

```text
├── AppCraft_Gallery.html        # Aplikasi Utama (Single Page App)
├── index.html                   # Entry point GitHub Pages
├── push_to_github.bat           # Skrip otomatis sinkronisasi & push ke GitHub
├── UI UX Mobile App/            # Folder koleksi UI HP
├── UI UX Web Dashboard/         # Folder koleksi Web Dashboard
├── Wireframes and Components/   # Folder wireframe & desain sistem
├── Poster and Typography/       # Folder poster & karya tipografi
├── Anime and Game Art/          # Folder anime & seni game
├── Wallpapers and Photography/  # Folder foto & wallpaper
└── README.md                    # Dokumentasi proyek
```

## 🌐 Menjalankan Online di GitHub Pages

Jalankan `push_to_github.bat` untuk menyinkronkan website `.html` beserta seluruh folder foto (~35MB) ke GitHub. Dalam 1-2 menit, website Anda di `https://appcraft1.github.io/Vault/` akan aktif dan dapat dibuka dari perangkat apa pun.
